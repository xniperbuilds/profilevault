## What it does

- **Unlimited Chrome profiles.** Each profile is its own separate Chrome — its own logins, cookies and settings. Set up one **MASTER** profile with the extensions and bookmarks you want, and every new profile is born with them already inside (your logins never copy over). Add a new extension later and **Sync to all** pushes it everywhere.

- **A proxy per profile that really works — and no leaks.** Chrome can't use a proxy that needs a username and password; ProfileVault can. It routes each profile through its proxy (HTTP or SOCKS5, with auth), resolves DNS at the proxy so your real DNS never shows, and if the proxy drops, the profile **stops** instead of leaking your real IP. A built-in **Guard** blocks the classic **WebRTC leak** and sets the **timezone to match your proxy's country** so nothing looks out of place. One click **Leak Check** shows the exit IP before you log in.

- **Two engines.** Use **Chrome** for things that need it (Netflix, Spotify, Google sign-in), or download the free **Antidetect (Chromium)** engine for real engine-level fingerprint protection — canvas, WebGL, audio, fonts — the thing other tools charge for.

- **Fresh like incognito, whenever you want.** New profiles start clean. Turn on **Fresh every time** and a profile wipes its cookies and history when you close it. Or hit **Clear data** to reset any profile — extensions and bookmarks stay.

- **Your emails, mapped.** One email, many sites. See **where each email is used** and which ones are still **free** for a given platform. Add them in bulk by pasting, or let any AI turn your messy notes into a ready import.

- **Reseller tools.** Subscriptions you buy, slots you sell, customers, profit, and one-tap **WhatsApp renewal messages** when something is due.

- **Secure notes & boards.** Cards, bank details, Wi-Fi, logins, software keys — from templates. A **Copy board** turns a pasted list into click-to-copy cells. **Temporary notes** delete themselves after a time you set.

- **Images & links, share templates, and more.** Keep screenshots and handy links in one place, build ready-to-send posts with your links filled in, and store a library of extensions.

- **Everything encrypted, nothing uploaded.** One master password (AES-256). No account, no telemetry, no cloud. Move it to another PC with one encrypted file.

## Install

1. **[Download the latest release](https://github.com/xniperbuilds/profilevault/releases/latest)** (`ProfileVault_Setup_x.y.z.exe` inside the zip).
2. Run it — no admin needed. It installs just the app, nothing bundled.
3. Open ProfileVault and set a master password. That password encrypts everything and **cannot be recovered**, so keep it safe.

The app **tells you inside** when a new version is out.

## Using a VPN or a proxy

- **System VPN (whole PC one country):** leave a profile's proxy **empty**, turn on the WebRTC guard, set timezone to **Auto**, and run **Leak Check** before logging in.
- **Different country per profile:** give each profile its own proxy — ProfileVault handles the auth and leaks for you.

## FAQ

**Is it really free?** Yes. No account, no paid tier, nothing held back.

**Does my data go anywhere?** No. It lives in one encrypted file on your PC. There's no server and no telemetry.

**I forgot my master password.** It can't be recovered — that's what makes the vault secure. Write it down somewhere safe.

**Can an AI assistant use it?** Optionally, yes — ProfileVault ships a local **MCP** server, so an MCP-capable assistant on your PC can manage profiles and accounts for you. It's off until you connect it in Settings.
